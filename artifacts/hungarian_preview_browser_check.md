The only English-looking text in the page chrome was the intentional language-switch target **English** and the product branding **CONSUL DEMOCRACY**.

The Hungarian sign-in route returned the Hungarian page title **Bejelentkezés**. The browser screenshot upload for that check was unavailable, so the detailed form-label verification is covered by the HTTP smoke test and subsequent page extraction checks.
